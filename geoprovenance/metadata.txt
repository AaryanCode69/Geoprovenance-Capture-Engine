# Person A owns this file. RULES.md §2.5 — any API newer than the floor below
# must be feature-detected at runtime, not assumed.
#
# qgisMinimumVersion was 3.34 (the LTS this project targets). Lowered to 3.28 on
# 24 Aug 2026 as a TESTING ACCOMMODATION, not a change of target: the only QGIS
# obtainable on the development machine is the Flathub LTS build, 3.28.9, and a
# 3.34 floor stops it loading the plugin at all. Nothing here has been verified
# against 3.34 itself.
#
# Checked before lowering: the newest QGIS API this plugin touches is
# QgsHistoryProviderRegistry and its entryAdded signal (capture/history_observer.py),
# both introduced in QGIS 3.24 — so 3.28 is safe for the code as written.
#
# Raise this back to 3.34 once a 3.34+ build is available. Findings recorded in
# docs/capture_coverage.md against 3.28.9 do not transfer to 3.34 unverified.
#
# qgisMaximumVersion is declared EXPLICITLY and must stay that way. When it is
# absent QGIS does not mean "no ceiling" — it derives one, by taking the FIRST
# CHARACTER of the minimum and appending ".99":
#
#     pyplugin_installer/installer_data.py:834 (QGIS 4.2.1)
#         qgisMaximumVersion = pluginMetadata("qgisMaximumVersion").strip()
#         if not qgisMaximumVersion:
#             qgisMaximumVersion = qgisMinimumVersion[0] + ".99"
#
# With qgisMinimumVersion=3.28 that is "3" + ".99" = 3.99, so QGIS 4.2.1 marked
# this plugin `incompatible` — "Plugin designed for QGIS 3.28 - 3.99" — and put
# it in the Plugin Manager's Invalid tab instead of the Installed one. Measured
# 26 Aug 2026. The window below spans the 3.x LTS this project targets and the
# 4.x build it is actually tested on.
